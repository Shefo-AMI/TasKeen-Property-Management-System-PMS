```bash

# Step 2: Login to Vercel

# Step 3: Deploy to production
vercel --prod
```

## 🐛 Troubleshooting

### Build Fails
```bash
# Clean install
rm -rf node_modules package-lock.json
npm install
npm run build

# If successful, deploy
vercel --prod
```

### Environment Variables Not Working
1. Verify `vercel.json` has correct values
2. Or add via Vercel Dashboard → Settings → Environment Variables
3. Redeploy after changes

### Can't Login After Deployment
1. Check browser console for errors
2. Verify Supabase URL in environment variables
3. Check Supabase Auth settings
4. Add your Vercel domain to Supabase allowed URLs:
   - Supabase Dashboard → Authentication → URL Configuration
   - Add: `https://your-app.vercel.app`

### API Errors
1. Test backend directly: `https://touwkydlhzxgwhnxpnui.supabase.co`
2. Check Edge Function logs in Supabase Dashboard
3. Verify CORS settings
4. Check authentication tokens
