## 🐛 Troubleshooting

### "Command not found: vercel"
```bash
# Install globally
npm install -g vercel

# Or use npx
npx vercel --prod
```

### Build Fails
```bash
# Test locally first
npm install
npm run build
npm run preview

# If successful, then deploy
vercel --prod
```

### Can't Login After Deployment
1. Check browser console for errors
2. Verify URL in browser address bar
3. Try in incognito/private window
4. Clear browser cache

### Environment Variables Issues
- Check `vercel.json` file is present
- Or add manually via Vercel Dashboard → Settings → Environment Variables
- Redeploy after changes
