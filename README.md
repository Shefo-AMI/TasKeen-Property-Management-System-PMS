# TasKeen Property Management System (PMS)

TasKeen PMS is a modern, scalable property management system built with React, TypeScript, Tailwind CSS, and Supabase.  
It manages tenants, leases, payments, and properties with real-time dashboards, role-based access, and smooth Vercel deployment.

## Running the Code

1. Run `npm i` to install dependencies.  
2. Run `npm run dev` to start the development server.
