## ⚙️ Optional Integrations

### Add Stripe Payments (Optional)
**When:** Whenever you want subscription billing

**How:**
1. Get Stripe key from https://stripe.com
2. Add to deployment: `VITE_STRIPE_PUBLIC_KEY=pk_test_...`
3. Redeploy

### Add Email Notifications (Optional)
**When:** Whenever you want automated emails

**How:**
1. Get Resend key from https://resend.com
2. Add to deployment: `VITE_RESEND_API_KEY=re_...`
3. Redeploy

**Both are optional and don't block deployment!**
